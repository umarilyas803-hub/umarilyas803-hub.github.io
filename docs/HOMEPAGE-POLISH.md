# Homepage composition

All eleven projects now share one filterable collection. Tools follow the work, with real logos and truthful exploration labels. The homepage uses a restrained pointer tilt on desktop; mobile offers static, horizontally scrollable tool rows. Motion pauses with the global control and follows reduced-motion preferences. Existing project URLs and legacy homepage anchors remain supported.
