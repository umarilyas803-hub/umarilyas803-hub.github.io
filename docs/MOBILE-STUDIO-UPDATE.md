# Mobile studio refinement

Mobile tool cards are compact and automatically move in opposite directions, matching the desktop toolkit. Both duplicated groups remain decorative and hidden from assistive technology. A local pause button, global motion pause, reduced-motion preference and offscreen/document visibility handling control the animation. Reduced motion restores manually scrollable rows.

Four service illustrations are built in native HTML/CSS with layered platforms, browser panels, workflow nodes and a search lens. The desktop service grid has two columns; phones show one readable card per row. The hero adds slow independent floating motion without replacing product-focus controls.

Shared buttons and header styling apply across the site. Homepage process, FAQ and message surfaces gain consistent depth. Mobile content stays visible rather than waiting for a reveal effect. No animation/video libraries or new raster downloads are required.
