# Custom visual assets

Created with built-in image generation for this redesign. These are illustrative scenes and concept interfaces, not real client evidence, real staff photographs or measured results. Generated source images are preserved outside the site source. The site uses optimized WebP derivatives in 640px and 1280px sizes, plus 1200 × 630 JPEG sharing previews.

The discarded mountain travel variation is not used: the existing Rift & Route demo is about Kenya, so the final image follows its actual content.

Motion uses CSS/JavaScript rather than animated bitmap files: restrained scroll reveals, a floating interface caption, hover image scaling and a feedback symbol. A persistent pause control and reduced-motion support disable animation. Important copy is HTML, never embedded only in a generated image.

Each production image has a descriptive alt attribute, dimensions and responsive variants. Below-fold images load lazily. Primary images are represented in the image sitemap and ImageObject structured data. Social preview text is typeset deterministically over the custom imagery. There are no fabricated ranking graphs or testimonial claims.
