# Approved compact homepage layout

Implements the approved preview for services, process and project grids. The toolkit section and all of its existing assets, styles and motion logic are unchanged.

Services use four columns on desktop and two on phones, with smaller sculptural icons and clear links. The process is an ordered, connected four-step row on desktop and a vertical timeline on phones. Projects retain three columns on desktop and use two on phones with concise typography and readable descriptions. Project types, links and category filters remain available.

Only the homepage, its scoped compact stylesheet and regression checks change. Existing demo pages and source assets are preserved.
