What this project is—and what it needs.

Aurelia House is a fictional hospitality demonstration, with generated images and no affiliation to a real hotel. The original application has a private, platform-authenticated demo workspace. This public portfolio walkthrough remains separate from that workspace.

There are no real bookings, card charges, tax invoices, notifications or OTA connections here. The staff directory does not create independent staff logins or enforce a hotel role system.
